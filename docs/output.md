# Toki — Output Guide

## Input format (W3C DTCG)

Toki consumes the [W3C Design Tokens Community Group (DTCG) format](https://design-tokens.github.io/community-group/format/):

```json
{
  "color": {
    "$type": "color",
    "primary": {
      "$value": "#1a73e8",
      "$description": "Primary brand color"
    },
    "secondary": {
      "$value": "{color.primary}",
      "$description": "Alias to primary"
    }
  },
  "spacing": {
    "$type": "dimension",
    "small": { "$value": "8px" },
    "medium": { "$value": "16px" }
  }
}
```

### Supported `$type` values

`color`, `dimension`, `fontFamily`, `fontWeight`, `duration`, `cubicBezier`, `number`, `lineHeight`, `letterSpacing`, `shadow`, `typography`, `border`, `transition`

### Reference syntax

`{group.token}` resolves to the referenced token's `$value`. References work inside strings, composite objects, and arrays.

## Output conventions

Generated artifacts always:

- Carry a header comment: `/* Generated by toki v{version} — do not edit */`
- Are deterministic (byte-identical for identical input)
- Have no runtime dependencies on toki

### Platform conventions

| Platform             | Convention                                                                                                                   |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **CSS**              | `:root` selector with `--kebab-case` custom properties                                                                       |
| **JavaScript**       | `export const camelCase` named exports + `.d.ts` declarations                                                                |
| **React Native**     | Values grouped by category (`colors`, `spacing`, …), raw numbers for dimensions (dp / sp), `StyleSheet.create()` helper file |
| **Angular (latest)** | SCSS variables consumed via `@use`, TypeScript `CONSTANT_CASE`, `InjectionToken<DesignTokens>` module for DI                 |
| **Angular 11**       | SCSS `@import` only (no `@use`/`@forward`), TypeScript `CONSTANT_CASE`, no `InjectionToken` module                           |
| **Svelte**           | `:root` CSS custom properties (cascade through scoped `<style>` blocks) + `camelCase` ES module                              |
| **React / Next.js**  | Nested theme object exported `as const` (CSS-in-JS and Tailwind `theme.extend` compatible) + companion CSS for `next-themes` |
| **StencilJS**        | `:root` CSS custom properties + `camelCase` ES module with grouped `tokens` object + per-category union types for type-safe `@Prop()` decorators |
| **Vue**              | `:root` CSS custom properties (cascade through scoped `<style>` blocks) + `camelCase` ES module                              |
| **Tailwind CSS v4**  | CSS-first `@theme` block with namespace-mapped custom properties (`--color-*`, `--spacing-*`, etc.)                          |

## Output examples

Given this input (`tokens.json`):

```json
{
  "color": {
    "$type": "color",
    "primary": { "$value": "#1a73e8", "$description": "Primary brand color" },
    "secondary": { "$value": "{color.primary}" }
  },
  "spacing": {
    "$type": "dimension",
    "small": { "$value": "8px" },
    "medium": { "$value": "16px" }
  },
  "font": {
    "$type": "fontFamily",
    "sans": { "$value": "Inter, sans-serif" }
  }
}
```

### CSS

`dist/css/tokens.css` — `:root` block with `--kebab-case` properties:

```css
/* Generated by toki v0.1.0 — do not edit */

:root {
  --color-primary: #1a73e8;
  --color-secondary: #1a73e8;
  --spacing-small: 8px;
  --spacing-medium: 16px;
  --font-sans: Inter, sans-serif;
}
```

### StencilJS

`dist/stencil/tokens.ts` — `export const` camelCase named exports + a grouped `tokens` object keyed by category:

```ts
/* Generated by toki v0.1.0 — do not edit */

export const colorPrimary = '#1a73e8';
export const colorSecondary = '#1a73e8';
export const spacingSmall = '8px';
export const spacingMedium = '16px';
export const fontSans = 'Inter, sans-serif';

export const tokens = {
  color: {
    primary: '#1a73e8',
    secondary: '#1a73e8',
  },
  spacing: {
    small: '8px',
    medium: '16px',
  },
  font: {
    sans: 'Inter, sans-serif',
  },
} as const;

export type TokenCategory = keyof typeof tokens;
```

`dist/stencil/tokens.d.ts` — companion type declarations for the named exports.

`dist/stencil/types.ts` — per-category union types (`ColorToken`, `SpacingToken`, …) and a full `TokenName` union for type-safe `@Prop()` decorators:

```ts
/* Generated by toki v0.1.0 — do not edit */

export type ColorToken =
  | 'color.primary'
  | 'color.secondary';

export type SpacingToken =
  | 'spacing.small'
  | 'spacing.medium';

export type FontToken =
  | 'font.sans';

export type TokenName =
  | ColorToken
  | SpacingToken
  | FontToken;
```

`dist/stencil/tokens.css` — `:root` block with `--kebab-case` custom properties (Stencil components consume them natively as CSS variables, even inside Shadow DOM).

```tsx
import { tokens, colorPrimary } from './tokens';
import type { ColorToken } from './types';

@Component({ tag: 'my-component' })
export class MyComponent {
  // Type-safe token name string
  @Prop() color: ColorToken = 'color.primary';

  render() {
    return <div style={{ background: `var(--color-${this.color})` }} />;
  }
}
```
